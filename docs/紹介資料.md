# NetworkToys 紹介資料

ネットワーク作業の前後を、測って・切り分けて・証跡に残すための Windows ツール

> 2026-08-17 版　／　対象: Windows 10・11 (x64)　／　ライセンス: MIT
> この資料は `docs/紹介資料.md` から `tools/docs/build_docx.py` で焼いています。

## 1. どういうツールか

現場でネットワークを触るとき、やることはいつも同じ形をしています。**作業前に測り、作業し、作業後にもう一度測って、違いを説明できる形で残す。** その一連を 1 つのアプリで済ませるために作ったのが NetworkToys です。

出発点は、現場で広く使われている **EXPing への不満**でした。ping が 1 宛先ずつ順番に実行されるため、宛先が増えるほど結果が出るまで待たされます。落ちている機器が 1 台混ざっているだけで、生きている機器の結果まで遅れて出てきます。

NetworkToys は **宛先ごとに独立した周期で並列に測ります。**応答しない相手が、他の相手を 1 ミリ秒も待たせません。100 件を超える宛先でも、状態は一目で追えます。

さらに、そのために立ち上げ直していた別々の道具 — TCP 疎通、DNS、traceroute、IP スキャン、無線 LAN、syslog 受信、機器へのログイン、設定の差分 — を同じアプリの中に入れてあります。**測る → 切り分ける → 記録する**が、画面を移るだけで続きます。

## 2. 特徴は 3 つ

### 待たされない

宛先ごとに独立した周期ループで測るので、死んでいるホストが他に影響しません。ホスト名は起動時に一度だけ解決して覚えるので、毎回 DNS を引く時間もかかりません。数百宛先でも画面はなめらかに動きます。

### 1 つに集まっている

**画面は 25 枚**あります。よく使う 6 枚を左に単独で並べ、たまにしか使わない 19 枚は右端の「その他」にまとめてあります（押すと 調べる / 受ける / NW機器 に分かれたメニューが降りてきます）。一覧の行を**右クリックすると、その相手を次の道具へそのまま渡せます** — アドレスを打ち直すことなく、ping の結果から経路調査へ、スキャンの結果からログ採取の対象へ移れます。

### そのまま証跡になる

測定結果は **HTML・テキスト・CSV** で書き出せます。HTML は画像も CSS も埋め込んだ 1 ファイル完結なので、客先のオフライン環境でもそのまま開けます。ほとんどの一覧に「CSV で保存」があり、機器の出力を表に直す画面は **絞り込みと見出し固定が付いた xlsx** で出せます。

CSV には、宛先ごとの統計に続けて**不通の記録が 2 つ目の表**として入ります。「平均 3.2ms・ロス 0.4%」という数字からは、いつ落ちていたのかが読み取れないからです。

## 3. 画面の一覧

**どの画面にも先頭に 1 行の説明**があり、左の ⓘ にマウスを載せると詳しい説明が出ます。

### いつも使う 6 枚

| 画面 | 何ができるか |
|---|---|
| **Ping** | 宛先ごとに独立した周期で並列 ping。応答なしを上段・応答ありを下段に分けて表示。状態バッジ・RTT・ロス率・推移のスパークライン。宛先リストの編集もこの画面で（EXPing と同じ書式のテキスト一括編集） |
| **Wi-Fi** | 接続中の AP の詳細、受信強度の推移、チャンネルの混み具合、周辺 AP の一覧 |
| **差分比較** | 機器の `show` 出力を作業前後で貼って見比べる。複数台・複数の対象を同時に抱えられる。SSH / Telnet で入って直に取ってくることもできる |
| **WFP** | Windows 自身が落とした通信の一覧。いつ・どのアプリが・どこへ出ようとして遮断されたか |
| **IP設定** | この PC の IPv4 設定（DHCP / 固定）とプロキシ設定の切り替え。現場ごとのプリセット保存つき |
| **業務確認** | 業務確認試験。Web・Teams・メールが使えるかを自動で判定し、CSV と HTML の報告書に |

### その他 → 調べる

| 画面 | 何ができるか |
|---|---|
| **TCP Ping** | 指定ポートへの接続で測る。ping が塞がれている相手の確認に。結果は接続・拒否・無応答の 3 状態 |
| **Traceroute** | 経路をたどる（TTL を並列に投げるので速い）。経路変化の見張りと Path MTU 探索 |
| **スキャン** | 範囲を指定してサブネットを掃き、MAC・ベンダー名・ホスト名・開放ポートを一覧に |
| **DNS** | 同じ名前を複数の DNS サーバへ同時に問い合わせて横並び比較 |
| **通信状況** | この PC のどのプロセスがどこと通信しているかをプロセス別に一覧 |
| **サブネット計算** | CIDR から範囲・分割案・マスク早見表 |

### その他 → 受ける

| 画面 | 何ができるか |
|---|---|
| **FTP / TFTP / SFTP** | 使い捨てのサーバを立てる。機器の `copy running-config` を受けてフォルダに保存 |
| **syslog** | 機器からの syslog を受けて一覧表示。重大度で色分けし「err 以上だけ」に絞れる |
| **SNMP Trap** | Trap の受信（UDP/162） |

### その他 → NW機器

| 画面 | 何ができるか |
|---|---|
| **ログ採取** | Cisco 機器へ SSH / Telnet で入り、`show` の出力を自動収集して 1 台 1 ファイルに |
| **showコマンド整形** | Cisco の出力を貼り付けると表に変換（8 種を自動判定）。xlsx か CSV で保存 |
| **ファイル転送** | FTP / SFTP のクライアント（2 ペイン）。取得・送信・改名・削除 |
| **SNMP Get** | v1 / v2c の GET とウォーク |
| **Meraki** | ダッシュボード API から機器・アップリンク・クライアント・DHCP・アラート・利用率、そして**拠点の導入時確認** |
| **Cisco ACI / WLC / Catalyst Center** | それぞれの API から状況を照会（**いずれも読み取り専用**） |

## 4. こんな場面で

### 機器を交換する日

作業前に宛先リストへ関係する機器を並べて測り始めます。作業中も測りっぱなしにしておけば、**いつ落ちて、いつ戻ったか**が不通の記録として残ります。作業後は同じ画面のまま結果を HTML に書き出せば、そのまま報告になります。

設定を触った機器は「差分比較」へ。`show ip route` は行の差分ではなく**構造として**突き合わせるので、経過時間だけが違う行が差分に出てくることはありません。

### 拠点を開設する日

Meraki の拠点なら「Meraki → 導入時確認」を押すだけで、**9 項目**を順に確かめます。

- 機器がすべて稼働しているか
- 有効にしてある WAN が全部リンクアップしているか
- 回線のロスと遅延（直近 5 分の実測値）
- スイッチのポートが 1000Mbps/Full か
- VPN の相手すべてに届いているか
- DHCP がセグメントごとに配れているか
- Teams を VPN から外す設定が入っているか
- 気になるイベントが出ていないか
- 端末が繋がっているか

判定は ○ / ✕ / △ で並び、そのまま CSV に落とせます。**API から判定できないもの**（アプライアンスのポート速度など）は「◍ 目視で確認」の行として残り、人が ○ か ✕ を押します。取れなかった項目を合格に丸めることはしません。

続けて「業務確認」で、Web が見られるか・Teams で通話できるか・メールサーバが応答するかを試験すれば、その日の確認は一通り終わります。

### プロキシや回線を入れ替えた日

「業務確認」は**プロキシを切り替えて同じ試験を回せます。**PAC でも固定アドレスでも登録でき、結果は 1 行 = 1 項目 × 1 プロキシで並ぶので、入れ替えの前後を隣り合わせで比べられます。**Windows のプロキシ設定は書き換えません**（他のアプリを巻き込まず、戻し忘れも起きません）。

Teams は **音声が通る UDP 3478〜3481 まで**確かめます。「チャットはできるのに通話だけ繋がらない」を、現地で捕まえるためです。

### 「繋がらない」と言われた日

ping が返らないなら TCP Ping、名前が引けないなら DNS（社内と外部を横並びで）、途中で止まっているなら Traceroute。**自分の PC が落としている**可能性は WFP と通信状況で確かめられます。切り分けの道具が同じアプリの中に揃っているので、原因の当たりが外れても次の一手がすぐ打てます。

## 5. 導入と運用

### 動作環境

| 項目 | 内容 |
|---|---|
| OS | Windows 10 / 11 (x64) |
| 権限 | **管理者権限は不要**。例外は WFP の一覧と通信状況の送受信量（OS の制限）、IP設定の適用（その瞬間だけ昇格） |
| 追加の準備 | 単一 exe 版なら不要。軽量版は .NET 10 Desktop Runtime が一度だけ必要 |
| 無線 LAN | Windows 11 24H2 以降は位置情報の許可が必要（OS の仕様変更。画面に案内と設定への導線が出ます） |

### 2 つの配布形態

| 成果物 | 展開後 | 中身 |
|---|---|---|
| `NetworkToys-win-x64` | 約 125MB | 単一 exe。.NET のインストール不要。**こちらを推奨** |
| `NetworkToys-win-x64-runtime-required` | 約 5MB | 軽量版。別途 .NET 10 Desktop Runtime が必要 |

WPF はトリミングできないため、.NET を同梱すると 125MB になります。圧縮すれば半分になりますが、メモリが倍・初回起動が 5 秒になるので採っていません。

### 持ち出せる

設定と宛先リストは **exe と同じフォルダ**に置かれます。フォルダごと USB メモリに入れれば、別の端末でも宛先リストがそのまま使えます（書き込めない場所に置いたときだけ `%APPDATA%` へ逃がします）。

### 起動時の警告について

**コード署名をしていないため、Chrome と Windows が警告を出します。**どちらも「危険なものが見つかった」ではなく「署名が無く、まだ広まっていないファイルだ」という意味です。Release には `SHA256SUMS.txt` を添えてあり、ビルドの全工程は GitHub Actions のログに残っています。

## 6. 安全のための決まりごと

道具として現場に持ち込むものなので、次を設計上の決まりとして守っています。

| 決まり | 中身 |
|---|---|
| **パスワードを保存しない** | 機器へのログイン・FTP・API キーのいずれも、保存もしなければ入れ物も作りません。覚えるのは接続先とユーザー名だけ。Meraki の API キーは入力欄も伏せ字です（画面を PNG で保存できるため） |
| **外部の機器は読み取り専用** | ACI・WLC・Catalyst Center・Meraki への問い合わせは参照だけです。設定を書き込む機能は持ちません |
| **危ないコマンドは実行前に弾く** | ログ採取で `reload` などを投げようとすると止めます。上書きするチェックボックスは用意していません |
| **管理者権限を前提にしない** | 全機能を通常のユーザー権限で動かす方針です |
| **状態を色だけで表さない** | `● 応答` `✕ 不達` `⊘ 拒否` のように記号と文字を必ず併記します。文字と地のコントラストは、CI が毎回検算しています |

## 7. 見た目と操作性

- 明るい配色と暗い配色を切り替えられます（選んだ配色は次回起動にも残ります）
- **文字サイズを 4 段階から選べます**（小 / 標準 / 大 / 特大）。行の高さも列幅も一緒に追随します
- フォントは Noto Sans JP を exe に同梱しているので、どの端末でも同じ字面になります
- 一覧の列幅は見出しの境目をドラッグして変えられます（次回起動にも残ります）
- ファイルはドラッグ＆ドロップで読み込めます。文字コードは UTF-8 と cp932 を自動で見分けます

## 8. よくある質問

**Q. EXPing の宛先リストをそのまま使えますか。**
使えます。書式を EXPing に合わせてあります。加えて範囲指定（`192.168.1.10-20` や `192.168.1.0/24`）とタブ区切りも受け付けます。

**Q. 測定中に宛先リストを直せますか。**
直せます。書き換えると自動で反映され、測定は止まりません。

**Q. 何台まで測れますか。**
数百宛先を想定して作ってあります（同時実行数は既定 64、設定で変更できます）。宛先ごとに独立して測るので、台数が増えても 1 台あたりの周期は変わりません。

**Q. 測定結果は自動で残りますか。**
残ります。測定を開始するたびに 1 結果 1 行のタブ区切りログが作られ、不通の発生と復旧もイベント行として残ります。30 日より古いログは起動時に自動で片付けます。

**Q. ポートスキャンは安全ですか。**
既定では無効です。有効にするとよく使う 22 ポートへ順に接続を試みます。ウイルス対策ソフトや EDR が反応することがあるため、**自分が管理権限を持つネットワークでのみ**お使いください。
