# PingWatcher の使い方

現場のネットワーク変更作業で「作業前に疎通を確かめ、作業中に見張り、作業後に証跡を残す」までを 1 つで済ませるためのツールです。管理者権限は要りません(例外は「接続」タブの通信量と「IP設定」の適用だけで、どちらも必要な瞬間にだけ昇格します)。

## まず動かす

1. `PingWatcher.exe` を起動します(インストール不要。フォルダごと USB に入れて持ち出せます)。
2. **「宛先」タブ**に測りたい相手を書きます。1 行 1 宛先で、アドレスの後ろに半角スペースを空けると備考になります。

   ```
   # 本社ネットワーク
   192.168.1.1 既定ゲートウェイ
   192.168.1.10 ファイルサーバ
   192.168.1.0/24
   8.8.8.8 外部疎通の基準
   ```

   行頭が `#` `;` `'` 全角スペースの行は注釈です。`192.168.1.10-20` や `192.168.1.0/24` の範囲指定、表計算からのタブ区切り貼り付けも受け付けます。書き換えると自動で反映されます。
3. ヘッダの**「開始」**を押すと Ping タブへ移り、全宛先を並列に測り始めます。応答しない宛先が他を待たせることはありません。

## メニューとヘッダ(全画面共通)

最上段のメニュー:

| メニュー | 項目 |
|---|---|
| ファイル | レポートの保存(HTML / テキスト / CSV)・画面を撮って保存(**F12**、`logs\screen-日時.png` へ)・データフォルダを開く・管理者として再起動・終了 |
| 測定 | 開始(**F5**)・停止(**Shift+F5**)・「Ping の測定結果だけ消す」・「すべて消す(起動直後に戻す。宛先リストは残る)」 |
| 表示 | 配色を切り替え・最前面に固定(チェック) |
| ヘルプ | 使い方を開く(このページ)・バージョン情報 |

よく使う操作はヘッダにも出ています:

| ボタン | 働き |
|---|---|
| 開始 / 停止 | 測定の開始と停止。開始すると Ping タブに移ります |
| クリア ▾ | 「Ping の測定結果だけ消す」か「すべて消す」を選択 |
| ☀ / ☾ | 明るい配色と暗い配色の切り替え(次回起動にも残ります) |

いまの接続環境(インターフェース / 自分の IP / ゲートウェイ / DNS)は「IP設定」タブの現在値で見られます。

### 一覧に共通の操作
どのタブの一覧も同じように扱えます。

- **見出しをクリックすると並べ替え**(もう一度で逆順、三度目で元の並び)。並べ替えた列に ▲▼ が出ます
- **見出しの境目をドラッグすると列幅**が変わります。幅は次回起動にも残ります

### 管理者として再起動
接続タブの通信量と遮断タブは管理者権限が要ります。「管理者として再起動」を選ぶと、**いまの状態をそのまま持って**起動し直します。

引き継がれるもの: 測定の途中経過(応答・ロス率・平均 RTT・スパークライン・作業前後の集計)、差分比較に貼り付けた機器の出力、各画面の入力欄、ウィンドウの位置と大きさ、開いていたタブ、測定が動いていたかどうか。

引き継がれないもの: 待受中のサーバ(FTP / TFTP / SFTP / syslog / SNMP Trap。ソケットはプロセスをまたげないので開き直してください)、進行中の処理(スキャンや traceroute はやり直し)、**Meraki の API キー**(保存しない決まりなので入れ直してください)。

## タブごとの使い方

### 宛先
宛先リストの一括編集。書式は上記のとおり。TCP で測る相手は「TCP」タブ側の欄に書きます(そちらは末尾 `:ポート` が測る先)。

### Ping
測定結果の一覧です。**2 回続けて応答が無い宛先は赤い「応答なし」欄に浮き上がる**ので、落ちた瞬間を見逃しません。

- 列: 状態 / 宛先 / 備考 / RTT / ロス / 推移(スパークライン)。**列の見出しをクリックすると並べ替え**(もう一度で逆順、三度目で元の並び)。見出しの境目をドラッグすると列幅を変えられます(次回起動にも残ります)
- 行を選ぶと画面下に詳しい統計(平均・最小最大・ジッタなど)が出ます
- **絞り込み欄**に打つと、宛先・備考・グループ・解決したアドレスの部分一致で表示を絞れます(測定は続いたままです)
- 行を**右クリック**すると、その宛先を **TCP Ping に追加**したり、**SSH / Telnet で接続**したり、経路調査・名前解決・アドレスのコピーができます
  - 「TCP Ping に追加」は TCP タブの宛先リストへ `宛先:ポート` の形で足します。ポートは TCP タブに入っている既定値です
  - 接続には **Tera Term** を使います。よくある導入先(`Program Files\teraterm5` など)と PATH から自動で探し、見つからないときだけ `ttermpro.exe` の場所を一度聞きます(次回からは覚えています)
  - TCP タブの宛先はそこに書いたポートへつなぎます。Ping タブの宛先は SSH なら 22、Telnet なら 23 です
- 状態は記号+文字で出ます: `● 応答` / `✕ 不通` / `⊘ 拒否` / `? 名前`(名前を引けない) / `… 停止`

### 経路
traceroute(TTL 並列で速い)・Path MTU 探索・経路変化の見張り。経路の見張りは ECMP の誤検知を避けるため 2 回連続で変わったときだけ「変化」と判定します。

### 無線
接続中 AP の詳細、受信強度(RSSI)の推移、チャンネルの混み具合、周辺 AP 一覧(見出しクリックで並べ替え可)。「保存」でいまの状況をテキストファイルに残せます。

> Windows 11 24H2 以降は OS の仕様で**位置情報の許可**が要ります。許可がない場合は画面の案内から設定を開けます。

### 収集
Cisco 機器へ **SSH / Telnet で入って `show` の出力を自動で集め、1 台 1 ファイルに保存**します。作業前後の証跡取りを、機器 1 台ずつ手で打つ代わりに一括で済ませられます。

1. **「宛先リストから選ぶ」**を押すと、Ping と TCP のタブに登録してある宛先が一覧で出ます。絞り込み欄で探して、取り込む相手にチェックを入れます(「表示中をすべて選ぶ」は絞り込んだ結果だけに効きます)。手で足すときは一覧の下の**「＋ 行を追加」**
2. 機器の行に、左から **機器のアドレス / 接続方法 / ユーザー名 / パスワード / enable** を入れます
   - **接続方法**は SSH か Telnet を選びます(既定は SSH)。ポートは方式に応じて 22 / 23 を使います
   - **enable** は特権モードに入るためのパスワードです。要らない機器は空のままで構いません
   - 要らない行はいちばん左の **✕** で消せます
3. 右の「コマンド」欄を確かめます。1 行 1 コマンドで、打つ順に並びます。機種のコンボで IOS / ASA / NX-OS を切り替えられます
4. 「収集を開始」。終わったら「保存先を開く」でファイルを確認できます

**待ち時間の 2 つのつまみ**は次の意味です。

| つまみ | 何を待つか |
|---|---|
| 接続の待ち | 機器につながるまで。過ぎたらその機器は諦めて次へ進みます |
| 応答の待ち | コマンドを送った後、**出力が途切れてから**諦めるまで。長い `show` でも出力が続いている間は待ち続けます |

**覚えるのはユーザー名だけです。** パスワードと enable パスワードは保存しません(設定ファイルにも、画面の PNG 保存にも、管理者として再起動したときの引き継ぎにも残しません)。収集が終わると入力欄も空になります。

**危ないコマンドは実行前に弾きます。** `reload` `configure terminal` `write` `copy` `clear` `debug` `erase` と、引数なしの `ping` / `traceroute` です。これらは機器が確認を求めてくるため自動では答えられず(答えるべきでもなく)、投げても止まるだけだからです。弾いたものは理由つきで画面に出ます。設定を変えたいときは Ping タブの右クリックから Tera Term でつないでください。

保存先は `collect\収集した日時\` で、ファイルはコマンドごとに見出しを入れた通しのテキストです。

### 差分
機器の `show` 出力を作業前後で貼って見比べます。対象は **show run(既定)/ show ip route / そのまま比較**。複数台ぶんを同時に抱えられるので、作業前にまとめて貼っておき、作業後にもう半分を貼るのが定石です。経路は構造として突き合わせるため、経過時間だけが違う行は差分になりません。

### スキャン
範囲を指定してサブネットを掃き、応答した機器の MAC・ベンダー名・ホスト名を一覧にします。そのまま宛先リストへ追加でき、「CSV で保存」で結果を Excel 用に書き出せます。ポート調査は既定で無効です(有効にするとウイルス対策ソフトが反応することがあります。自分が管理するネットワークでのみ使ってください)。

### TCP
TCP 接続で測る独立した画面です。ping(ICMP)が塞がれている相手の確認に使います。結果は 3 状態 — つながる / **拒否(ホストは生きているがポートが閉じている)** / 無応答 — で、この区別が切り分けの決め手になります。

### FTP(サブタブ: FTP / TFTP / SFTP)
使い捨てのファイル受け渡しサーバです。機器の `copy running-config ftp:` などを受けて `ftp\` 等のフォルダに保存します。画面にそのまま打てるコマンド例が表示されます。FTP/TFTP は平文・認証なしなので**使うときだけ開始**してください。SFTP は暗号化されます。

### DNS
同じ名前を複数の DNS サーバへ同時に問い合わせて横並び比較します。「社内 DNS では引けるが外部では引けない」の切り分けに。A / AAAA / CNAME / MX / NS / TXT / SOA / SRV / PTR に対応。

### syslog
機器からの syslog を受けて一覧表示します。機器側に `logging <この PC の IP>` を入れるだけです。受信内容は `logs\` にも残ります。初回は Windows ファイアウォールの許可が要ります。

### SNMP(サブタブ: GET / Trap)
v1/v2c の GET・ウォークと、Trap の受信(UDP/162)。sysDescr などよく使う OID のプリセットがあります。

### 接続
この PC のどのプロセスがどこと TCP/UDP 通信しているかを、リソースモニターのようにプロセスごとにまとめて表示します。

- 既定は**一時停止**で、タブを開いた瞬間の 1 枚だけを表示します。「一時停止」を外すと 2 秒ごとに追いかけます
- 絞り込み欄でプロセス名・アドレス・ポート・状態の部分一致検索。列見出しクリックで並べ替え(送信/受信の列はプロセスの合計順になります)
- **通信量(送受信 B/秒)だけは管理者権限が必要**です(ETW という OS の仕組みの制限)。非管理者では「—」表示になり、案内行の「管理者として再起動」ボタンから昇格して起動し直せます。接続一覧そのものは非管理者で見えます

### IP設定
この PC のアダプタを選んで、DHCP と固定 IP(IP・マスク・ゲートウェイ・DNS×2)を切り替えます。

1. アダプタを選ぶと現在の設定が入力欄に入ります(抜けている=未接続のアダプタも選べます)
2. 「DHCP で自動取得する」を外して固定 IP を入力(マスクは `255.255.255.0` / `24` / `/24` のどれでも可)。入力の誤りやゲートウェイがサブネット外のときはその場で表示されます
3. 「適用」→ 内容の確認 → **UAC の昇格確認(1 回)** で反映されます。アプリ自体は非管理者のまま動きます
4. よく使う現場の設定は「プリセット」に名前を付けて保存できます(選ぶと入力欄に入るだけで、適用は必ず「適用」ボタンから)

> 適用するとこの PC の通信が一時的に切れることがあります。リモートデスクトップ越しの操作では特に注意してください。

下段の**プロキシ**では、Windows のプロキシ設定(現在のユーザー)を「使わない / PAC / 固定サーバ」から選んで適用できます。こちらは管理者権限も UAC も不要で、ブラウザなどのシステムプロキシにすぐ反映されます(動作中のアプリは再起動後に反映されることがあります)。

### 計算
サブネット電卓。CIDR かマスク付き IP を入れると、ネットワーク/ブロードキャスト/ホスト範囲/分割案を表示します。/8〜/32 の早見表つき。

### パース
Cisco コマンドの出力を貼り付けると **CSV に変換**します。Excel で加工したい・台帳に貼りたいときに。

1. 機器で打った出力(スクロールバックごとで構いません)を上の欄に貼り付けます
2. 種類は自動判定されます(決まらないときは「種別」から選択)
3. 下の欄に CSV プレビューが出るので、「CSV で保存」(BOM 付き UTF-8、Excel でそのまま開けます)か「コピー」

対応コマンド: `show ip route` / `show ip interface brief` / `show cdp neighbors` / `show mac address-table` / `show interfaces status` / `show inventory` / `show version` / `show logging`

### 遮断
Windows Filtering Platform(WFP)が落とした通信を一覧にします。「疎通しない」原因が経路や機器ではなく**この PC のファイアウォールだった**、というときの切り分けに。

**管理者権限が必要です**(読み取りだけでも要ります)。管理者でないときは案内と「管理者として再起動」ボタンが出ます。

さらに Windows は既定でネットワークイベントを記録していません。記録が切られていると 0 件のままなので、その場合は「記録を有効にする」を押してください。

- これは **PC 全体に効く設定**です。押す前に確認ダイアログが出ます
- PingWatcher を閉じるときに**元へ戻します**。もともと有効だった環境の設定には触りません

| 列 | 内容 |
|---|---|
| 時刻 | 最後にその遮断が起きた時刻 |
| 方向 | `→ 送信` / `← 受信` |
| プロトコル | TCP / UDP / ICMP など |
| 送信元・宛先 | IP:ポート |
| プロセス | 遮断された実行ファイル名(完全なパスはマウスを当てると出ます) |
| 件数 | 同じ遮断が何回起きたか |

どのフィルタで落ちたかの番号(フィルタ ID / 層 ID)は画面には出しませんが、**CSV には残ります**。`netsh wfp show filters` で規則を引き当てるときに使えます。

**この一覧に出るのは「この PC の WFP がフィルタで落とした通信」だけです。** Windows Defender ファイアウォールのブロック規則による遮断はここに含まれます。逆に、IPsec 関連の破棄、ストアアプリの権限による遮断、MAC 層の遮断、受信のマルチキャスト/ブロードキャストの遮断(Windows が既定で記録しません)、そして相手側やネットワーク機器で落とされた通信は出ません。

まったく同じ遮断は 1 行にまとめて件数で表します(生のまま並べると同じ行が数百件続いて読めません)。「一時停止」を外すと 5 秒ごとに追いかけます。「CSV で保存」で書き出せます。

### Meraki
Meraki ダッシュボード API から、組織配下の情報をまとめて引きます。ダッシュボードにログインして拾い集める代わりに使えます。

1. ダッシュボードの **[My profile] → API access** で発行した API キーを、上の「API キー」欄に貼り付けます(伏せ字。**保存されません**ので毎回入力します)
2. 「取得」を押します。組織が複数あるときは一覧が出るので、「組織」から選んでもう一度「取得」を押します
3. 下のサブタブに結果が出ます。それぞれ「CSV で保存」できます(BOM 付き UTF-8)

| サブタブ | 出る内容 |
|---|---|
| ネットワーク | ネットワーク名 / ID / 製品種別 / タイムゾーン / タグ |
| 機器 | 名前 / 型番 / **シリアル** / **ファームウェア** / ネットワーク / 状態 / グローバル IP / LAN IP |
| アップリンク | MX の WAN1・WAN2 ごとに 状態 / IP / ゲートウェイ / **グローバル IP**(上に全体の要約も出ます) |
| クライアント | 名前 / IP / MAC / VLAN / メーカー / 通信量 / 最終確認 |

クライアントだけは**ネットワークを 1 つ選んで**別に取得します(呼び出し回数の制限があるため)。期間は 1 時間 / 1 日 / 7 日 / 30 日から選べます。

- API キーは設定ファイルにも記録にも残しません。「すべて消す」で入力欄ごと空になります
- 状態は `● 稼働` `⊘ 警報` `◌ 休止` `✕ 停止` のように記号と文字で表します
- 社内プロキシは Windows の設定がそのまま使われます

### 記録
書き出される内容のプレビューがそのまま表示されます。**HTML**(1 ファイル完結。オフライン環境でも開ける)/ **テキスト**(報告書・チケット貼り付け用。等幅で桁が揃う)/ **CSV**(Excel 用)で保存できます。応答の無かった宛先・不通の発生と復旧の時刻・`ipconfig /all`・無線の情報と周辺 AP 一覧が入ります。

## 作業前後の比較(実運用の流れ)

1. 作業前: 宛先リストを整えて「開始」。しばらく流して基準を作る
2. 差分タブに作業前の `show run` / `show ip route` を貼っておく
3. 作業を実施(測定は流しっぱなしに。不通の発生・復旧は時刻つきで自動記録されます)
4. 作業後: 差分比較に作業後の出力を貼って変化を確認
5. 「記録」タブから HTML かテキストで書き出して証跡に。画面そのものは「ファイル → 画面を撮って保存」(F12)で PNG に

## データの保存先

設定・宛先リスト・記録はすべて **exe と同じフォルダ**に置かれます(`Program Files` など書き込めない場所に置いたときだけ `%APPDATA%\PingWatcher\`)。フォルダごと USB にコピーすれば、別の端末でも同じ宛先リスト・設定で使えます。

| 場所 | 中身 |
|---|---|
| `settings.json` | すべての設定（Ping/TCP の宛先リスト・測定の既定値・配色・列幅） |
| `logs\` | 測定ログ(1 結果 1 行のタブ区切り)とスクリーンショット |
| `sessions\` | 作業セッションの記録 |
| `ftp\` `tftp\` `sftp\` | ファイルサーバの受け渡しフォルダ |
| `collect\` | 収集タブが集めた機器の出力(1 台 1 ファイル)。自動では消しません |

測定ログは 30 日より古いものを起動時に自動で片付けます(スクリーンショットは消しません)。

## 困ったとき

- **起動時に「Windows によって PC が保護されました」と出る** — コード署名をしていないためです。「詳細情報」→「実行」で起動できます
- **無線タブに何も出ない** — Windows 11 24H2 以降は位置情報の許可が必要です。画面の案内から設定を開いてください
- **接続タブの送信/受信が「—」のまま** — 通信量の表示だけは管理者権限が必要です。案内行の「管理者として再起動」から昇格できます
- **syslog / Trap が届かない** — 初回は Windows ファイアウォールの許可ダイアログで「アクセスを許可」を選んでください
- **測っているのに全行「… 停止」になった** — スリープ復帰などで測定が止まった状態です。「停止」→「開始」で再開してください
