# NetworkToys の使い方

> **この文書は、アプリの中からも読めます。**`NetworkToys.exe` を起動して **ヘルプ → 使い方** を開いてください。
> 中身は同じですが、見出しや表が組まれて出るので**そちらの方が読みやすい**です。
> このファイル(`使い方.md`)は、アプリを起動せずに読みたいときや、人に渡すときに使ってください。

現場のネットワーク変更作業で「作業前に疎通を確かめ、作業中に見張り、作業後に証跡を残す」までを 1 つで済ませるためのツールです。管理者権限は要りません(例外は「通信状況」タブの通信量と「IP設定」の適用だけで、どちらも必要な瞬間にだけ昇格します)。

## できること

**測る・見張る**

- **Ping**: 何百でも並列に ping を打ち続け、応答・遅延・ロスを一覧で見張る(落ちた相手は上段へ浮き上がる)
- **TCP Ping**: ICMP が塞がれている相手を、ポートへの接続で測る
- **Traceroute**: 経路・Path MTU・経路変化の見張り
- **Wi-Fi**: 接続中の AP と電波、周辺 AP のチャンネル混雑
- **通信状況**: この PC のどのプロセスがどこと通信しているか(管理者なら送受信 B/秒 も)

**調べる**

- **スキャン**: 範囲を掃いて MAC・ベンダー・ホスト名・開放ポートを一覧に
- **DNS**: 同じ名前を複数の DNS サーバへ同時に問い合わせて横並び比較
- **サブネット計算**: CIDR / マスクの電卓と分割案
- **SNMP Get**: v1/v2c の GET・ウォーク

**確かめる・残す**

- **業務確認**: Web・Teams・メールが使えるかを、**プロキシを切り替えて**まとめて試験し、成績書に残す
- **差分比較**: 機器の `show` 出力を作業前後で突き合わせる(**機器から直に取ってこられる**)
- **WFP**: Windows 自身が落とした通信の一覧(遮断の切り分け)
- **記録**: レポートを HTML / テキスト / CSV で保存

**機器を相手にする**

- **ログ採取**: Cisco 機器へ SSH / Telnet で入り、決めた `show` を**並行して**集めて 1 台 1 ファイルに保存
- **showコマンド整形**: 貼り付けた `show` の出力を表に変換して Excel / CSV へ
- **ファイル転送**: FTP / SFTP のクライアント(2 ペイン)
- **受ける側**: FTP / TFTP / SFTP / syslog / SNMP Trap の使い捨てサーバ

**クラウド・コントローラから読む**(いずれも読み取り専用)

- **Meraki**: 導入時確認・機器・アップリンク・クライアント・拠点・DHCP・アラート
- **ACI**: ヘルス・フォールト・ポート・EPG・エンドポイント・BD・機器一覧と、テナント設定の前後比較
- **WLC**: Catalyst 9800 へ SSH で入り、端末・AP・参加/切断・電波・不正 AP・SSID を表に

**手元の設定を変える**

- **IP設定**: IPv4 設定の切り替え(プリセット)と、WinINET / WinHTTP 両方のプロキシ設定

## まず動かす

1. `NetworkToys.exe` を起動します(インストール不要。フォルダごと USB に入れて持ち出せます)。
2. **「宛先リスト」タブ**に測りたい相手を書きます。1 行 1 宛先で、アドレスの後ろに半角スペースを空けると備考になります。

   ```
   # 本社ネットワーク
   192.168.1.1 既定ゲートウェイ
   192.168.1.10 ファイルサーバ
   192.168.1.0/24
   8.8.8.8 外部疎通の基準
   ```

   行頭が `#` `;` `'` 全角スペースの行は注釈です。`192.168.1.10-20` や `192.168.1.0/24` の範囲指定、表計算からのタブ区切り貼り付けも受け付けます。書き換えると自動で反映されます。
3. ヘッダの**「開始」**を押すと Ping タブへ移り、全宛先を並列に測り始めます。応答しない宛先が他を待たせることはありません。

## メニューとヘッダ(全画面共通)

最上段のメニュー:

| メニュー | 項目 |
|---|---|
| ファイル | レポートの保存(HTML / テキスト / CSV)・画面を撮って保存(**F12**、`logs\screen-日時.png` へ)・データフォルダを開く・管理者として再起動・「Ping の測定結果だけ消す」・「すべて消す(起動直後に戻す。宛先リストは残る)」・終了 |
| 表示 | ライトモード / ダークモードの切り替え・最前面に固定(チェック)・**文字サイズ**(小 / 標準 / 大 / 特大)・列幅を既定に戻す |
| ヘルプ | 使い方を開く(このページ)・バージョン情報 |

**ヘッダの帯はありません。**メニューの下がすぐタブで、画面を縦に広く使えます
(2026-08-16 にヘッダ 1 行を廃止しました)。

- 測定の**開始と停止は Ping タブの中だけ**にあります(**F5** / **Shift+F5** でも打てます)
- **消す操作**はメニューの「ファイル」に
- **ライトモード / ダークモードの切り替え**はメニューの「表示」に(次回起動にも残ります)。
  ボタンはメニュー帯の右端にもあります
- **文字サイズ**もメニューの「表示」から変えられます(小 / 標準 / 大 / 特大)。
  タブの中身だけでなく、**メニュー・ツールチップ・別窓・一覧の行の高さ**まで一緒に変わります。
  **一覧の列幅も同じ割合で伸び縮み**するので、文字が切れません
  (自分で広げた列の割合はそのまま保たれます)。次回起動にも残ります

測定の状態・保存の結果・ファイルを読み込んだ知らせは、メニューの帯の**右端**に出ます。

いまの接続環境(インターフェース / 自分の IP / ゲートウェイ / DNS)は「IP設定」タブの現在値で見られます。

### 一覧に共通の操作
どのタブの一覧も同じように扱えます。

- **見出しをクリックすると並べ替え**(もう一度で逆順、三度目で元の並び)。並べ替えた列に ▲▼ が出ます
- **見出しの境目をドラッグすると列幅**が変わります。幅は次回起動にも残ります

### 管理者として再起動
接続タブの通信量とWFP タブは管理者権限が要ります。「管理者として再起動」を選ぶと、**いまの状態をそのまま持って**起動し直します。

引き継がれるもの: 測定の途中経過(応答・ロス率・平均 RTT・スパークライン・作業前後の集計)、差分比較に貼り付けた機器の出力、各画面の入力欄、ウィンドウの位置と大きさ、開いていたタブ、測定が動いていたかどうか。

引き継がれないもの: 待受中のサーバ(FTP / TFTP / SFTP / syslog / SNMP Trap。ソケットはプロセスをまたげないので開き直してください)、進行中の処理(スキャンや traceroute はやり直し)、**Meraki の API キー**・**APIC のパスワード**・**WLC のパスワード**(いずれも保存しない決まりなので入れ直してください)。

## タブごとの使い方

タブは 7 枚です。よく使う画面を左に単独で並べ、たまにしか使わない道具は
いちばん右の**「その他」**にまとめてあります。

**どのタブにも先頭に 1 行の説明**があり、左の `ⓘ` にマウスを載せると詳しい説明が出ます
(「その他」は中身を選ぶだけの入れ物なので、説明はありません)。

| タブ | 中身 |
|---|---|
| Ping / Wi-Fi / 差分比較 / WFP / IP設定 / 業務確認 / Meraki | それぞれ 1 画面 |
| **その他　17 ▾** | 下記の 3 分類・17 画面 |

「その他」を押すと、**分類ごとに並んだメニュー**が降りてきます。

| 分類 | 中身 |
|---|---|
| 調べる | TCP Ping / Traceroute / スキャン / DNS / 通信状況 / サブネット計算 |
| 受ける | FTP / TFTP / SFTP / syslog / SNMP Trap |
| NW機器 | ログ採取 / showコマンド整形 / ファイル転送 / SNMP Get / ACI / WLC |

- **メニューは項目を選ぶまで画面を変えません**
  (見に行っただけのつもりで、測定中の画面から飛ばされないように)
- 帯には**いま開いているものだけ**が出ます(19 枚並べると名前が読めないため)。
  別のものに切り替えるときは、もう一度「その他」を押してメニューから選びます
- 一覧の右クリックから別の道具へ送ったときは、**畳まれた先まで開きます**

宛先リストは Ping の画面に畳みました。Ping タブの**「宛先リスト ▾」**を押すと編集欄が開きます。

### Ping
測定結果の一覧です。**「宛先リスト ▾」**を押すと、測る相手を書く欄がこの画面の中で開きます
(1 行 1 宛先。書き換えると自動で反映され、測定は止まりません。
宛先を書いたファイルをこの欄に**放り込んでも読み込めます**)。**2 回続けて応答が無い宛先は赤い「応答なし」欄に浮き上がる**ので、落ちた瞬間を見逃しません。

- 列: 状態 / 宛先 / 備考 / RTT / ロス / 推移(スパークライン)。**列の見出しをクリックすると並べ替え**(もう一度で逆順、三度目で元の並び)。見出しの境目をドラッグすると列幅を変えられます(次回起動にも残ります)
- 行を選ぶと画面下に詳しい統計(平均・最小最大・ジッタなど)が出ます
- **絞り込み欄**に打つと、宛先・備考・解決したアドレスの部分一致で表示を絞れます(測定は続いたままです)
- 行を**右クリック**すると、その宛先を **TCP Ping に追加**したり、**SSH / Telnet で接続**したり、経路調査・名前解決・アドレスのコピーができます
- 同じ右クリックは **スキャン / 接続 / 遮断 / Meraki / syslog / SNMP Trap** の一覧にもあります。見つけた相手を Ping・TCP・収集へ足したり、経路や名前を調べたりを打ち直しなしで行えます
  - 「TCP Ping に追加」は TCP Ping の宛先リストへ `宛先:ポート` の形で足します。ポートは TCP Ping に入っている既定値です
  - 送り先はタブ名と同じ言い方にしてあります(「Traceroute を実施」「DNS 解決」「SNMP Get で問い合わせ」「ログ採取の機器に追加」)
  - 接続には **Tera Term** を使います。よくある導入先(`Program Files\teraterm5` など)と PATH から自動で探し、見つからないときだけ `ttermpro.exe` の場所を一度聞きます(次回からは覚えています)
  - TCP Ping タブの宛先はそこに書いたポートへつなぎます。Ping タブの宛先は SSH なら 22、Telnet なら 23 です
- 状態は記号+文字で出ます: `● 応答` / `✕ 不通` / `⊘ 拒否` / `? 名前`(名前を引けない) / `… 停止`

### Wi-Fi
接続中 AP の詳細、受信強度(RSSI)の推移、チャンネルの混み具合、周辺 AP 一覧(見出しクリックで並べ替え可)。「保存」でいまの状況をテキストファイルに残せます。

> Windows 11 24H2 以降は OS の仕様で**位置情報の許可**が要ります。許可がない場合は画面の案内から設定を開けます。

### 差分比較
機器の `show` 出力を作業前後で貼って見比べます。対象は **show run(既定)/ show ip route / そのまま比較**。複数台ぶんを同時に抱えられるので、作業前にまとめて貼っておき、作業後にもう半分を貼るのが定石です。経路は構造として突き合わせるため、経過時間だけが違う行は差分になりません。

**機器から直に取ることもできます。**「作業前」「作業後」それぞれの「機器から」を押すと小窓が開き、接続先・**SSH / Telnet**・ユーザー名・パスワード・enable パスワードを入れて `show` を 1 本流し、その出力がそのまま欄に入ります。

- 流すコマンドは**いま選んでいる対象**から決まります(`show run` なら `show running-config`)。打ち替えられますが、**危ないコマンドは弾きます**(ログ採取と同じ物差し。上書きの手段はありません)
- **パスワードは保存しません。**アプリを閉じるまでのあいだ覚えるのは接続先・ユーザー名・方式だけで、設定ファイルには書きません
- 読み込みは**置き換え**です(ファイルから読むときと同じ。混ざると誤った差分を見ることになるため)
- Telnet は暗号化されません。SSH が使えない機器のときだけにしてください

### WFP
Windows Filtering Platform(WFP)が落とした通信を一覧にします。「疎通しない」原因が経路や機器ではなく**この PC のファイアウォールだった**、というときの切り分けに。

**管理者権限が必要です**(読み取りだけでも要ります)。管理者でないときは案内と「管理者として再起動」ボタンが出ます。

さらに Windows は既定でネットワークイベントを記録していません。記録が切られていると 0 件のままなので、その場合は「記録を有効にする」を押してください。

- これは **PC 全体に効く設定**です。押す前に確認ダイアログが出ます
- NetworkToys を閉じるときに**元へ戻します**。もともと有効だった環境の設定には触りません

| 列 | 内容 |
|---|---|
| 時刻 | 最後にその遮断が起きた時刻 |
| 方向 | `→ 送信` / `← 受信` |
| プロトコル | TCP / UDP / ICMP など |
| 送信元・宛先 | IP:ポート |
| プロセス | 遮断された実行ファイル名(完全なパスはマウスを当てると出ます) |
| 件数 | 同じ遮断が何回起きたか |

どのフィルタで落ちたかの番号(フィルタ ID / 層 ID)は画面には出しませんが、**CSV には残ります**。`netsh wfp show filters` で規則を引き当てるときに使えます。

**この一覧に出るのは「この PC の WFP がフィルタで落とした通信」だけです。** Windows Defender ファイアウォールのブロック規則による遮断はここに含まれます。逆に、IPsec 関連の破棄、ストアアプリの権限による遮断、MAC 層の遮断、受信のマルチキャスト/ブロードキャストの遮断(Windows が既定で記録しません)、そして相手側やネットワーク機器で落とされた通信は出ません。

まったく同じ遮断は 1 行にまとめて件数で表します(生のまま並べると同じ行が数百件続いて読めません)。「一時停止」を外すと 5 秒ごとに追いかけます。「CSV で保存」で書き出せます。

### IP設定
この PC のアダプタを選んで、DHCP と固定 IP(IP・マスク・ゲートウェイ・DNS×2)を切り替えます。

1. アダプタを選ぶと現在の設定が入力欄に入ります(抜けている=未接続のアダプタも選べます)
2. 「DHCP で自動取得する」を外して固定 IP を入力(マスクは `255.255.255.0` / `24` / `/24` のどれでも可)。入力の誤りやゲートウェイがサブネット外のときはその場で表示されます
3. 「適用」→ 内容の確認 → **UAC の昇格確認(1 回)** で反映されます。アプリ自体は非管理者のまま動きます
4. よく使う現場の設定は「プリセット」に名前を付けて保存できます(選ぶと入力欄に入るだけで、適用は必ず「適用」ボタンから)

> 適用するとこの PC の通信が一時的に切れることがあります。リモートデスクトップ越しの操作では特に注意してください。

下段の**プロキシ**は 2 段構えです。**Windows には別々のプロキシ設定が 2 つあり、片方だけ直して原因が分からなくなるのが定番の落とし穴**なので、両方をここに並べています。

| どちら | 誰が従うか | 権限 |
|---|---|---|
| 上段(WinINET) | ブラウザなど。ログインしたユーザーごとの設定 | 不要 |
| 下段(**WinHTTP**) | サービスとして動くもの — Windows Update・監視エージェント・.NET のアプリ・PowerShell の一部。**PC 全体で 1 つ** | 適用時に UAC が 1 回 |

「ブラウザは見えるのに Windows Update やエージェントだけ外に出られない」というときは、下段が空のままなのが原因です。

- **どちらも同じ形で操作します** — 方式を選び、必要な欄を埋めて「適用」
- 上段は「使わない / PAC / 固定サーバ」、下段は「使わない / 固定サーバ」から選びます
- **WinHTTP は PAC を扱えません**(「直接」か「固定」しか持てない仕様です)。
  そのため下段の選択肢に PAC はありません。PAC の現場では、PAC が返す代表的なプロキシを固定で入れてください
- 開いた時点で**いまの設定が入力欄に入っています**。`netsh winhttp show proxy` と同じ内容ですが、
  **表示言語に左右されない API から直に読んで**います

### 業務確認
ネットワークやプロキシを入れ替えたあとの**業務確認試験**です。自動で判定できるところを肩代わりし、結果は報告書に落として試験成績書へ貼れます(タブの「HTML で保存」は**ファイル → レポートを HTML で保存**と同じもので、測定の結果も一緒に入ります。CSV やテキストもファイルメニューからどうぞ)。

1. 「ひな型を入れる」で項目の枠を入れ、**宛先を現場に合わせて書き換えます**
2. 上の欄にプロキシを書き、**試すものにチェック**を入れます
3. 「まとめて実行」を押します。下に結果が並びます

#### 項目の書き方
表で編集します。列は 削除 / 項目名 / 種類 / 宛先 / 期待 / 結果。

| 種類 | 宛先に書くもの | 合格の条件 |
|---|---|---|
| HTTP | URL | 2xx か 3xx が返る。「期待」に文字列を書くと本文に含まれることまで見る |
| TCP | `host:port` | 接続できる |
| SMTP / IMAP / POP3 | `host:port`(省略すると 587 / 993 / 995) | サーバの第一声が `220` / `* OK` / `+OK` で始まる |
| DNS | 引きたい名前。**空なら自分のホスト名** | 答えが 1 件以上返る |
| Teams | 空でよい | 名前解決・HTTPS 443・音声の UDP がすべて通る |
| fast.com | 空でよい | 測れる(上り・下りの両方) |
| 速度 / 速度上り | 測る URL(上りは末尾 `\|20` で 20MB) | 測れる |
| 手動 | ブラウザで開く URL | **人が ○ / ✕ を押す** |

「期待」欄は種類で意味が変わります。HTTP は**本文に含まれるべき文字列**、速度と fast.com は**目安の Mbps**です。

#### プロキシを切り替えて比べる
1 行 1 件で `名前,種類,アドレス` と書きます。種類は `pac` か `proxy` です。

```
Zscaler,pac,http://pac.zscaler.net/example/proxy.pac
i-FILTER,pac,http://pac.example.jp/proxy.pac
旧プロキシ,proxy,10.0.0.10:8080
```

「直接」と「いまの設定」は常に選べます。初回は「いまの設定」が選ばれているので、まず現状が通ることを確かめてから他を試すと順序が自然です。

結果は **1 行 = 1 項目 × 1 プロキシ**で、同じ項目の行が隣り合うので左右に比べられます。

- **Windows のプロキシ設定は書き換えません。** 他のアプリを巻き込まず、戻し忘れも起きません
- **PAC は試験する URL ごとに引き直します。** PAC は宛先で答えが変わるためで、証跡には**実際に選ばれたプロキシ**まで出ます
- 認証は**統合 Windows 認証**で通ります。通らないと `HTTP 407` が返ります
- **プロキシを通るのは HTTP・速度・Teams だけ**です。TCP・メール・DNS は直接出るので、何本選んでも 1 回しか試験しません

#### Teams は経路が 2 つに分かれます
署名・チャット・在席は HTTPS なので**プロキシを通り**、音声・映像の UDP 3478〜3481 は**直接出ます**。どちらも同じ項目の中で確かめます。

「チャットはできるのに通話だけ繋がらない」は UDP が塞がれているときに起きます。ただ UDP を投げても無応答では開いているか塞がれているか分からないので、**応答が返る問い合わせ(STUN)**を送って判定します。通ったら続けて往復時間・ゆらぎ・欠落を測ります(目安は往復 200ms / ゆらぎ 30ms / 欠落 1%)。

#### 遮断ページを合格と読みません
フィルタリング製品は遮断したときに**自前のページを HTTP 200 で返す**ことがあります。応答コードだけを見ていると、目的のサイトに届いていないのに合格になります。

**確実にしたい項目は「期待」欄に文字列を書いてください**(ログイン画面なら「ログイン」など)。書かない場合も、よくある遮断の文言が出ていれば不合格にします。証跡には**最終 URL と Server ヘッダ**を必ず残すので、誰が返したか後から追えます。

#### ブラウザでないと開けないページ
ログインが要る・証明書を選ぶ・JavaScript で描画される、といったページはアプリからは判定できません。種類を「手動」にすると**ブラウザで開くところまで**を行い、結果は「◍ 目視で確認」になります。その行に出る **○ / ✕** を押して合否を付けてください。押すと結果が差し替わり、CSV にもそのまま載ります。

**SharePoint / OneDrive など、サインインが要るページは「手動」にしてください。** HTTP で叩くと **403** が返ります(アプリはブラウザのセッションを持たないため)。403 は「経路は通っているが認証していない」という意味なので、名前解決・プロキシ・TLS までは確かめられていますが、合否としては不合格に見えます。

**プロキシを複数選んでいるときは、手動の項目も 1 つずつ回します。** ブラウザは Windows のプロキシ設定に従うので、アプリが**その設定を切り替えて**から開きます。○ / ✕ を付けると次のプロキシに切り替えて開き直し、**すべて終わると元の設定に戻します**(切り替えている間は画面に断りが出ます)。

人の判定が残っているうちは「すべて合格」とは表示しません。

- 既定のブラウザで開くので、**Windows のプロキシ設定に従います**。業務確認タブで選んだプロキシとは別物です

#### 合否は 3 段です
`○ 合格` / `△ 注意` / `✕ 不合格`。**注意は「通ってはいるが目安を割っている」**ときに出ます(通話の品質が悪い、速度が目安を下回る)。合格に丸めると現場で拾えず、不合格にすると受け入れ試験として厳しすぎるためです。

#### ひな型を自分で作る
現場ごとに試す項目は決まっているので、**いまの項目に名前を付けて残せます**。

1. 項目を書く（既存のひな型を入れてから直すのが早いです）
2. **「ひな型に残す」**を押して名前を付けます。同じ名前があれば上書きします
3. 次からはコンボの一覧に **★ 付き**で出ます

自作のひな型は `settings.json` に入るので、exe ごと持ち出せば別の PC でもそのまま使えます。
消すときは選んでから「ひな型を消す」。**組み込みのひな型（標準 / Microsoft 365）は消せません。**
組み込みと同じ名前で残すと、自分のものが優先されます。

#### 項目の持ち回り
「項目を保存」「項目を読み込む」でファイルに出し入れできます。現場ごと・案件ごとに使い分けたり、人に渡したりできます。書式は画面と同じ `項目名,種類,宛先,期待` の 1 行 1 件で、行頭 `#` は注釈です。BOM 付き UTF-8 なので Excel で作って読み込ませることもできます。

なお終了時に settings.json へも覚えるので、次に開けば前回の続きから始められます。

#### fast.com について
**公開 API ではありません。**ページ内のスクリプトからトークンを抜き出す必要があるため、**先方の作りが変われば動かなくなります**。そのときは「スクリプトからトークンを読み取れませんでした」のように**どこで躓いたか**が出ます。

常用するなら「速度」で URL を直に指定する方が確実です。

### 調べる
相手や自分の状態を確かめる道具です。タブを押すと出るメニューから選びます。

#### TCP Ping
TCP 接続で測る独立した画面です。ping(ICMP)が塞がれている相手の確認に使います。結果は 3 状態 — つながる / **拒否(ホストは生きているがポートが閉じている)** / 無応答 — で、この区別が切り分けの決め手になります。

#### Traceroute
traceroute(TTL 並列で速い)・Path MTU 探索・経路変化の見張り。経路の見張りは ECMP の誤検知を避けるため 2 回連続で変わったときだけ「変化」と判定します。

#### スキャン
範囲を指定してサブネットを掃き、応答した機器の MAC・ベンダー名・ホスト名を一覧にします。そのまま宛先リストへ追加でき、「CSV で保存」で結果を Excel 用に書き出せます。ポート調査は既定で無効です(有効にするとウイルス対策ソフトが反応することがあります。自分が管理するネットワークでのみ使ってください)。

#### DNS
同じ名前を複数の DNS サーバへ同時に問い合わせて横並び比較します。「社内 DNS では引けるが外部では引けない」の切り分けに。A / AAAA / CNAME / MX / NS / TXT / SOA / SRV / PTR に対応。

#### 通信状況
この PC のどのプロセスがどこと TCP/UDP 通信しているかを、リソースモニターのようにプロセスごとにまとめて表示します。

- 既定は**一時停止**で、タブを開いた瞬間の 1 枚だけを表示します。「一時停止」を外すと 2 秒ごとに追いかけます
- 絞り込み欄でプロセス名・アドレス・ポート・状態の部分一致検索。列見出しクリックで並べ替え(送信/受信の列はプロセスの合計順になります)
- **通信量(送受信 B/秒)だけは管理者権限が必要**です(ETW という OS の仕組みの制限)。非管理者では「—」表示になり、案内行の「管理者として再起動」ボタンから昇格して起動し直せます。接続一覧そのものは非管理者で見えます

#### サブネット計算
サブネット電卓。CIDR かマスク付き IP を入れると、ネットワーク/ブロードキャスト/ホスト範囲/分割案を表示します。/8〜/32 の早見表つき。

### NW機器
ネットワーク機器を相手にする道具です。タブを押すと出るメニューから選びます。

#### ログ採取
Cisco 機器へ **SSH / Telnet で入って `show` の出力を自動で集め、1 台 1 ファイルに保存**します。作業前後の証跡取りを、機器 1 台ずつ手で打つ代わりに一括で済ませられます。**機器は同時に 8 台まで並行**して取りに行きます(踏み台や認証サーバに殺到しないための上限です)。

1. **「宛先リストから選ぶ」**を押すと、Ping と TCP のタブに登録してある宛先が一覧で出ます。絞り込み欄で探して、取り込む相手にチェックを入れます(「表示中をすべて選ぶ」は絞り込んだ結果だけに効きます)。手で足すときは一覧の下の**「＋ 行を追加」**
2. 機器の行に、左から **機器のアドレス / 接続方法 / ユーザー名 / パスワード / enable** を入れます
   - **接続方法**は SSH か Telnet を選びます(既定は SSH)。ポートは方式に応じて 22 / 23 を使います
   - **enable** は特権モードに入るためのパスワードです。要らない機器は空のままで構いません
   - 要らない行はいちばん左の **✕** で消せます
3. 右の「コマンド」欄を確かめます。1 行 1 コマンドで、打つ順に並びます。機種のコンボで IOS / ASA / NX-OS を切り替えられます
4. 「収集を開始」。終わったら「保存先を開く」でファイルを確認できます

**待ち時間の 2 つのつまみ**は次の意味です。

| つまみ | 何を待つか |
|---|---|
| 接続の待ち | 機器につながるまで。過ぎたらその機器は諦めて次へ進みます |
| 応答の待ち | コマンドを送った後、**出力が途切れてから**諦めるまで。長い `show` でも出力が続いている間は待ち続けます |

**覚えるのはユーザー名だけです。** パスワードと enable パスワードは保存しません(設定ファイルにも、画面の PNG 保存にも、管理者として再起動したときの引き継ぎにも残しません)。収集が終わると入力欄も空になります。

**危ないコマンドは実行前に弾きます。** `reload` `configure terminal` `write` `copy` `clear` `debug` `erase` と、引数なしの `ping` / `traceroute` です。これらは機器が確認を求めてくるため自動では答えられず(答えるべきでもなく)、投げても止まるだけだからです。弾いたものは理由つきで画面に出ます。設定を変えたいときは Ping タブの右クリックから Tera Term でつないでください。

保存先は `collect\収集した日時\` で、ファイルはコマンドごとに見出しを入れた通しのテキストです。

#### showコマンド整形
Cisco コマンドの出力を貼り付けると **表に変換**します。Excel で加工したい・台帳に貼りたいときに。

1. 機器で打った出力(スクロールバックごとで構いません)を上の欄に貼り付けます
2. 種類は自動判定されます(決まらないときは「種別」から選択)
3. 下の欄にプレビューが出るので、次のどれかで持ち出します
   - **Excel で保存** — `.xlsx`。**絞り込み(オートフィルタ)と見出し行の固定が付いた状態**で開きます。数字だけの欄は数値として入るので、並べ替えも数値の絞り込みもそのまま効きます(`007` のような先頭 0 の表記や製造番号は文字のまま残します)
   - **CSV で保存** — BOM 付き UTF-8 のテキスト。Excel でそのまま開けますが、**書式は持てないので絞り込みは付きません**(開いてから `Ctrl+Shift+L`)
   - **コピー** — CSV テキストをクリップボードへ

対応コマンド: `show ip route` / `show ip interface brief` / `show cdp neighbors` / `show mac address-table` / `show interfaces status` / `show inventory` / `show version` / `show logging`

なお**差分比較タブで構造として突き合わせられるのは `show ip route` だけ**です(残りは行の差分になります)。表として見たいときはこちらで CSV に変換してください。

#### ファイル転送
FTP / SFTP の**クライアント**です。WinSCP のような 2 ペインで、**左が この PC、右が 接続先**。
機器やサーバに置いてあるファイルを取ってくる・置いてくるときに使います
(「受ける」の FTP / SFTP はこの逆で、相手から送りつけてもらうためのものです)。

1. 上の欄に **接続先 / SFTP か FTP / ポート / ユーザー / パスワード** を入れて「接続」
   (種類を切り替えるとポートも 22 / 21 に付いてきます)
2. 右の一覧に接続先の中身が出ます。**フォルダはダブルクリックで入り、`↰ ..` で戻ります**
3. 運びたいファイルを選んで **「→ 送る」/「← 取ってくる」**
4. 「新しいフォルダ」「名前を変更」「削除」は接続先に効きます

- **転送は必ずバイナリで行います。** 改行が勝手に変換されないので、設定ファイルが壊れません
- **削除と上書きは確認の窓が出ます。**元に戻せないので、名前をよく見てください
- **パスワードは保存しません。**閉じると消えます
- SFTP は繋いだ相手の**ホスト鍵の指紋**を欄に出します。前と違っていたら、
  相手が入れ替わっている疑いがあります(欄の文字はコピーできるので証跡に残せます)
- 大きなファイルを運んでいる間は下に進み具合が出ます。止めたいときは「中断」
- 日本語のファイル名は、**FTP では文字コードがサーバ任せ**なので化けることがあります
  (SFTP は UTF-8 と決まっているので化けません)

#### SNMP Get
v1/v2c の GET とウォーク。sysDescr などよく使う OID のプリセットがあります。Trap の受信は「受ける」タブへ移しました。

#### Meraki
Meraki ダッシュボード API から、組織配下の情報をまとめて引きます。ダッシュボードにログインして拾い集める代わりに使えます。

1. ダッシュボードの **[My profile] → API access** で発行した API キーを、上の「API キー」欄に貼り付けます(伏せ字。**保存されません**ので毎回入力します)
2. 「取得」を押します。組織が複数あるときは一覧が出るので、「組織」から選んでもう一度「取得」を押します
3. 下のサブタブに結果が出ます。それぞれ **Excel(絞り込みと見出し固定つき)** か **CSV**(BOM 付き UTF-8)で保存できます

| サブタブ | 出る内容 |
|---|---|
| 機器 | **全拠点**の 名前 / 型番 / **シリアル** / **ファームウェア** / 拠点 / 状態 / **LAN IP**(MX は拠点の VLAN 設定から補います) |
| アップリンク | MX の WAN1・WAN2 ごとに 状態 / IP / ゲートウェイ / **グローバル IP**(上に全体の要約も出ます。**停止中の機器の回線は出しません**) |
| クライアント | 拠点 / 名前 / IP / MAC / VLAN / メーカー / 通信量 / 最終確認（**拠点を選ぶか「全拠点」か**を選べます） |
| 拠点 | 拠点ごとの**クライアント数(期間は選べます)**と、**実際に使われているセグメント**(MX の VLAN とスタティックルート) |
| DHCP | MX ごとの**払い出し済み / 空き / 使用率**(70% で注意、90% で警告の色) |
| アラート | 組織で出ている**アラート**(重大度 / 種別 / 拠点 / 機器 / 発生時刻) |

クライアントは**拠点を 1 つ選ぶか「全拠点」**を選んで取得します。**全拠点は途中で打ち切らず最後まで取る**ので、拠点が多いと数分かかります（画面に断りが出ます。待てないときは「中断」）。期間は 1 時間 / 1 日 / 7 日 / 30 日から選べます。

- API キーは設定ファイルにも記録にも残しません。「すべて消す」で入力欄ごと空になります
- 状態は `● 稼働` `⊘ 警報` `◌ 休止` `✕ 停止` のように記号と文字で表します
- 拠点タブの「拠点ごとに数える」は**拠点の数だけ問い合わせる**ので時間がかかります(40 拠点で打ち切り)
- **クライアントが 1 台も居ないセグメントは出しません**(設定だけ残っている経路を並べても、拠点の実態を読み違えるため)。ここで数えたセグメントは、機器タブの MX の「LAN IP」にも足されます
- DHCP とアラートは、先に「取得」を押して機器一覧と組織を確定させてから使います
- 社内プロキシは Windows の設定がそのまま使われます

#### ACI
APIC の REST からファブリックの状態を読み取ります。**読み取り専用**で、設定を書き込む機能はありません(フォールトの確認応答も持ちません)。

1. 上の欄に **APIC の IP かホスト名**(`https://` は付けても付けなくても構いません)・**ユーザー**・**パスワード**を入れます。接続先は前回のものが入っています
   - 読み取りだけできるユーザーで十分です
2. 「取得」を押すと、**ヘルス**と**フォールト**、それにポート画面で使うノードの一覧と、差分比較で使うテナントの一覧が取れます
3. ほかのサブタブは、それぞれの「〜を取得」を押したときだけ通信します

| サブタブ | 出る内容 |
|---|---|
| ヘルス | ファブリック全体 / ノード / テナントの健全度。95 以上が良好、80 未満は不良として色を変えます |
| フォールト | いま出ている障害を重い順に。情報レベルは既定で除いています |
| ログ | **障害の履歴**(faultRecord)と**イベント**(eventRecord)を種別で切り替え |
| ポート | 選んだノードの物理ポートと**ポートチャネル**。管理状態と実際の状態、速度、**そのポートに載っている EPG と VLAN・タグ付け(trunk/access)**、落ちている理由 |
| EPG | EPG の一覧と、選んだ EPG に結び付いたポート(静的パス)・VLAN・モード |
| エンドポイント | 学習済みの MAC と IP、その EPG と接続先のポート |
| 機器一覧 | ファブリックの機器を **型番 / シリアル / 版 / 状態** つきで（`fabricNode`。ノード番号順） |
| BD | ブリッジドメインを **ルーティングの有無 / ネットワークアドレス / VRF** つきで |
| 差分比較 | **テナントの設定を作業の前と後で取って、その場で左右に並べて見比べます** |

**作業前後の設定比較について。** 「差分比較」サブタブで**テナントを選び、作業の前に「作業前を取得」**を押します。作業を終えたら**「作業後を取得」→「比較」**で、左右に並べて見比べられます(このタブの中で完結します)。

- 取るのは**設定だけ**です(`rsp-prop-include=config-only`)。稼働値(カウンタ・時刻・状態)を混ぜると、**設定を何も変えていなくても差分だらけ**になるためです
- APIC は**子の並び順を約束しません**。そのままでは並びが変わっただけで差分になるので、こちらでクラス→DN→名前の順に**並べ替えてから**字下げした行に直しています
- `modTs` や `uid` のような、設定ではない属性は落とします(実機で余計な差分が出るときは、その属性名を教えてください。落とす一覧に足せます)
- 左右はそれぞれ**横にスクロール**できます(長い行のため)。縦は互いに合わせます。「異なる行だけ」で変わったところだけに絞れます
- **書き込みはしません。**APIC 自身のスナップショット(Config Rollback)を作る機能は、設定を書く操作なのでこのアプリには持たせていません。既存のスナップショットの一覧は種別「設定バックアップ」で見られます
- **スイッチ単位で見たいとき**は、leaf / spine の管理 IP に対して差分比較タブの「機器から」で SSH し、`show running-config` を取る手もあります(ただしそちらは APIC が配った結果の写しで、設定の原本ではありません)

**証明書の確認について。** APIC は自己署名の証明書を使っていることが多く、そのままでは繋ぎません。初回の接続で**指紋(SHA-256)を出して確認**しますので、APIC の画面に出ている指紋と見比べて、同じであれば受け入れてください。受け入れた指紋は記録され、次からは聞かれません。**前と違う指紋になったときは、黙って通さずもう一度確認します**(相手が入れ替わっている可能性があるため)。

- **パスワードは保存しません。**覚えるのは接続先とユーザー名だけです
- 各一覧は **Excel(絞り込みと見出し固定つき)**か **CSV** で保存できます
- エンドポイントの行を右クリックすると、その IP を Ping や経路へ送れます
- 件数が多いと途中で打ち切ります。打ち切ったときは必ずその旨を上に出します
- 表が空なのに通信はできているように見えるときは、「応答を表示」で生の応答を確かめてください(APIC の版で属性名が違うことがあります)
- 練習用に、Cisco DevNet の常時稼働 ACI サンドボックスが使えます。接続先の候補に出しているのは**ホスト名だけ**なので、**ユーザー名とパスワードは DevNet のサンドボックスのページで確認**してください(こちらに書き写すと、変わったときに嘘になります)

#### WLC
Catalyst 9800 へ **SSH で入って `show` を流し**、無線の状態を読み取ります。**読み取り専用**で、設定を書き込む機能はありません(AP の再起動なども持ちません)。

**WLC 側の準備。** SSH で入れれば使えます(RESTCONF は要りません)。読み取りだけできるユーザー(特権 15)で構いません。

1. 上の欄に **WLC のアドレス**・**ユーザー**・**パスワード**を入れます
2. 「取得」を押すと、**端末**と **AP** が取れます(この 2 つで大半の用は足ります)
3. ほかのサブタブは、それぞれの「〜を取得」を押したときだけ通信します

| サブタブ | 出る内容 |
|---|---|
| 端末 | **IP か MAC で端末を探し、どの AP に繋がっているか**を見ます。SSID / 帯域とチャンネル / RSSI / 品質 / 速度も出ます |
| AP | AP の一覧。**繋がっていない AP も同じ表に混ざります**(「未接続だけ」で絞れます) |
| 参加・切断 | AP が**最後に参加した時刻・最後に切れた時刻とその理由**、参加の回数 |
| 電波 | AP の無線ごとのチャンネル・出力・**混み具合**・雑音・台数 |
| 不正 AP | 周囲で見えている**野良 AP と隣接 AP**。分類・電波強度・検知した AP |
| SSID | SSID ごとの**接続台数と帯域別の内訳**(2.4 / 5 / 6GHz) |

**端末の探し方。** 探す欄は **IP でも MAC でも AP 名でも SSID でも**構いません。MAC は `aabb.ccdd.eeff` / `AA:BB:CC:DD:EE:FF` / `aa-bb-cc-dd-ee-ff` のどの書き方でも当たります。取ってきた一覧の中から絞るので、打ち直しても通信はしません。

**「無線が遅い」と言われたら。**「電波の弱い順」を押すと、RSSI の弱い端末から並びます(見出しをクリックしても並べ替わります)。

**繋がっていない AP について。** 「✕ 未接続」は、**WLC は知っているのに繋がっていない** AP です。設定にも参加記録にも無い AP は WLC 自身が知らないので出せません。

**証明書の確認について。** WLC は自己署名の証明書を使っていることが多く、そのままでは繋ぎません。初回の接続で**指紋(SHA-256)を出して確認**しますので、WLC の画面と見比べて、同じであれば受け入れてください。前と違う指紋になったときは、黙って通さずもう一度確認します。

**表の作り方。** 「取得」を押すと `show ap summary` などを流し、**すべてのタブの表を作ります**(ボタンは 1 つだけです)。桁の位置は版で変わるので、**見出し行から列を学習して**読みます(読めなかった行は捨てます)。`show` の要約に無い項目(端末の IP・電波の強さ・混み具合)は **「—」**のままです。元にした出力は「取得した出力」で読めます。

- **パスワードは保存しません。**覚えるのは接続先とユーザー名だけです
- 各一覧は **Excel(絞り込みと見出し固定つき)**か **CSV** で保存できます
- 端末と AP の行を右クリックすると、その IP を Ping や経路へ送れます
- 表が空なのに通信はできているように見えるときは、「応答を表示」で生の応答と**投げた URL**を確かめてください(IOS-XE の版でリーフ名が違うことがあります)

#### FTP / TFTP / SFTP
使い捨てのファイル受け渡しサーバです。機器の `copy running-config ftp:` などを受けて `ftp\` 等のフォルダに保存します。画面にそのまま打てるコマンド例が表示されます。FTP/TFTP は平文・認証なしなので**使うときだけ開始**してください。SFTP は暗号化されます。

#### syslog
機器からの syslog を受けて一覧表示します。機器側に `logging <この PC の IP>` を入れるだけです。受信内容は `logs\` にも残ります。初回は Windows ファイアウォールの許可が要ります。

**重大度の列**があり、`err` 以下は赤、`warning` は橙で出ます(色だけでなく文字でも出ます)。上の欄で「warning 以上」「err 以上」に絞れます。本文と送信元での絞り込みと、「CSV で保存」「一覧を消す」もあります。絞っても**待受は止まりません**。

#### SNMP Trap
SNMP Trap の受信(UDP/162)。varbind は件数で打ち切らず、長い行は一覧で省略して全文を ToolTip に出します。

## ファイルを放り込んで読み込む

**ファイルの読み込みは、どこもドラッグ＆ドロップでできます。** 対応するのは次の欄です。

| 放り込む先 | 何を読むか |
|---|---|
| Ping →「宛先リスト ▾」の欄 | 宛先を書いたテキスト |
| 差分比較 の作業前 / 作業後 | 機器から落とした設定やコマンドの出力 |
| NW機器 → showコマンド整形 の貼り付け欄 | Cisco コマンドの出力 |
| 業務確認 の項目一覧 | 試験項目のファイル |

- **いまの内容は置き換わります**（足すのではありません）。前のものが混ざったまま気づかず
  誤った差分を見る方が危ないためです
- **文字コードは自動で見分けます。** UTF-8 として読めなければ cp932(Shift_JIS)として読み直すので、
  TeraTerm のログや機器から落としたファイルもそのまま開けます
- 複数まとめて放り込んだときは 1 つ目だけを読み、その旨をヘッダに出します

## 記録の書き出し

**ファイル → レポートを…で保存**から書き出します。**HTML**(1 ファイル完結。オフライン環境でも開ける)/ **テキスト**(報告書・チケット貼り付け用。等幅で桁が揃う)/ **CSV**(Excel 用)で保存できます。応答の無かった宛先・不通の発生と復旧の時刻・業務確認試験の結果・`ipconfig /all`・無線の情報と周辺 AP 一覧が入ります。

**無線の情報は「Wi-Fi」タブを開いていなくても入ります。** 書き出す直前に 1 度だけ読みます
(スキャンはしないので通信は途切れません)。位置情報の許可が無くて読めなかったときは、その旨が記録に残ります。

**Ping と TCP の両方**が 1 つの記録に入ります(種別の列で見分けられます)。不通の記録も両方から集めます。

CSV は宛先ごとの統計の表に続けて、**空行をはさんで「不通の記録」の表**が入ります。1 宛先に何度も起きるので行の意味が違い、別の表にしてあります。Excel はこの形をそのまま開けます。

**業務確認試験の結果も同じ記録に入ります。**試験だけを HTML にしたいときは、業務確認タブの「HTML で保存」から出せます。

## 作業前後の比較(実運用の流れ)

1. 作業前: 宛先リストを整えて「開始」。しばらく流して基準を作る
2. 差分比較タブに作業前の `show run` / `show ip route` を貼っておく
3. 作業を実施(測定は流しっぱなしに。不通の発生・復旧は時刻つきで自動記録されます)
4. 作業後: 差分比較に作業後の出力を貼って変化を確認
5. 「ファイル → レポートを HTML で保存」で書き出して証跡に。画面そのものは「ファイル → 画面を撮って保存」(F12)で PNG に

## データの保存先

設定・宛先リスト・記録はすべて **exe と同じフォルダ**に置かれます(`Program Files` など書き込めない場所に置いたときだけ `%APPDATA%\NetworkToys\`)。フォルダごと USB にコピーすれば、別の端末でも同じ宛先リスト・設定で使えます。

| 場所 | 中身 |
|---|---|
| `settings.json` | すべての設定（Ping/TCP の宛先リスト・測定の既定値・配色・列幅） |
| `logs\` | 測定ログ(1 結果 1 行のタブ区切り)とスクリーンショット |
| `sessions\` | 作業セッションの記録 |
| `ftp\` `tftp\` `sftp\` | ファイルサーバの受け渡しフォルダ |
| `collect\` | ログ採取タブが集めた機器の出力(1 台 1 ファイル)。自動では消しません |

測定ログは 30 日より古いものを起動時に自動で片付けます(スクリーンショットは消しません)。

## 困ったとき

- **起動時に「Windows によって PC が保護されました」と出る** — コード署名をしていないためです。「詳細情報」→「実行」で起動できます
- **無線タブに何も出ない** — Windows 11 24H2 以降は位置情報の許可が必要です。画面の案内から設定を開いてください
- **接続タブの送信/受信が「—」のまま** — 通信量の表示だけは管理者権限が必要です。案内行の「管理者として再起動」から昇格できます
- **syslog / Trap が届かない** — 初回は Windows ファイアウォールの許可ダイアログで「アクセスを許可」を選んでください
- **測っているのに全行「… 停止」になった** — スリープ復帰などで測定が止まった状態です。「停止」→「開始」で再開してください
