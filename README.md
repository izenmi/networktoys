# PingWatcher

ネットワーク変更作業の前後で、疎通を確かめて記録に残すための Windows 向けツール。

EXPing のように宛先リストへ ping を打てますが、**宛先ごとに独立した周期で並列に測定する**ので、応答しない宛先が他の宛先を待たせません。100 件以上の宛先でも一目で状態を追えます。

ping のほかに TCP 接続・DNS・traceroute・IP スキャン・無線 LAN、そして**作業前後の比較**と**機器の設定差分**まで 1 つのアプリにまとめてあり、結果はそのまま現場の証跡として書き出せます。

画面ごとの詳しい使い方は **[docs/USAGE.md](docs/USAGE.md)** にあります。

## できること

| 画面 | 内容 |
|---|---|
| **宛先** | EXPing と同じ書式でまとめて編集。範囲指定でサブネットを一気に登録。書き換えると自動で反映され、測定は止まりません |
| **Ping** | 宛先ごとに独立した周期で並列 ping。**応答なしを上段、応答ありを下段**に分けて表示。状態バッジ・RTT・ロス率・推移のスパークライン（平均やジッタは行を選ぶと下の詳細欄に出ます）。1 行 1 宛先の詰めた一覧で、列幅はヘッダの境目をドラッグして変えられます |
| **TCP** | TCP 接続で測る独立した画面。ping が塞がれている相手の確認に。宛先リストも Ping とは別に持ちます |
| **差分比較** | 機器の `show` 出力を作業前後で貼って見比べます。**複数台・複数の対象**を同時に抱えられるので、作業前にまとめて貼っておけます |
| **スキャン** | 範囲を指定してサブネットを掃き、MAC・ベンダー名・ホスト名・開放ポートを一覧に。そのまま宛先へ追加できます |
| **計算** | サブネット電卓。CIDR かマスク付き IP を入れると、ネットワーク/ブロードキャスト/ホスト範囲/分割案を表示。/8〜/32 のマスク早見表つき |
| **FTP** | 使い捨ての FTP サーバ。機器の `copy running-config ftp:` を受けて `ftp\` フォルダに保存します。**平文なので使うときだけ開始**。PASV/PORT 両対応 |
| **TFTP** | 使い捨ての TFTP サーバ（UDP/69）。機器の `copy … tftp:` を受けて `tftp\` フォルダへ。blksize 交渉に対応。**認証なしなので使うときだけ開始** |
| **SFTP** | 使い捨ての SFTP サーバ（SSH 越しで暗号化）。WinSCP などで `sftp\` フォルダへ読み書き。ホスト鍵は初回に生成して保存 |
| **DNS** | 同じ名前を複数の DNS サーバへ同時に問い合わせて横並び比較。A / AAAA / CNAME / MX / NS / TXT / SOA / SRV / PTR |
| **経路** | traceroute（TTL を並列に投げるので速い）、Path MTU 探索、経路変化の見張り |
| **syslog** | 機器からの syslog を受けて一覧表示。`logging <このPCのIP>` を機器に入れるだけ。`logs\` にも保存 |
| **SNMP** | v1/v2c の GET・ウォークと、Trap 受信（UDP/162）。sysDescr など主要 OID のプリセットつき |
| **無線** | 接続中 AP の詳細、受信強度の推移、チャンネルの混み具合、周辺 AP 一覧。「保存」でいまの状況をテキストに残せます |
| **接続** | この PC のどのプロセスがどこと TCP/UDP 通信しているかをプロセス別に一覧(リソースモニター風)。管理者起動時は接続ごとの送受信 B/秒 も表示 |
| **IP設定** | この PC のアダプタを選んで DHCP/固定 IP を切り替え(現場ごとのプリセット保存つき。適用時だけ UAC 昇格)。Windows のプロキシ設定(なし/PAC/固定)もここから変えられます(こちらは UAC 不要) |
| **パース** | Cisco コマンドの出力(show ip route / interfaces status / inventory / version / logging など 8 種)を貼り付けると CSV に変換。種類は自動判定 |
| **Meraki** | ダッシュボード API から ネットワーク / 機器(シリアル・ファーム) / MX のアップリンクとグローバル IP / クライアント を取得。各一覧を CSV 保存。API キーは保存しない(毎回入力・伏せ字) |
| **記録** | HTML・テキスト・CSV で書き出し |

Ping と TCP の一覧は、行を**右クリック**するとその宛先の経路や名前をそのまま調べられます。

### 差分比較でできること

`show ip route` / `show ip interface brief` / `show cdp neighbors` / `show mac address-table` は、
**行の差分ではなく構造として**突き合わせます。経過時間（`00:15:23` など）や Holdtime は
無視するので、設定を何も変えていないのに全行が差分になる、ということが起きません。

`show run` とそれ以外は行の差分で、左右に並べて色分けします。「前の差分」「次の差分」でたどれます。

## 宛先の書き方

「宛先」タブにまとめて書けます。書式は EXPing に合わせています。

```
# 本社ネットワーク
192.168.1.1 既定ゲートウェイ
192.168.1.10 ファイルサーバ
192.168.1.20-22 プリンタ

; 外部疎通
8.8.8.8 Google Public DNS
```

- 1 行に 1 宛先。アドレスの後ろに**半角スペース**を空けると、そこから行末までが備考
- 行頭が `#` `;` `'` **全角スペース** の行は注釈として読み飛ばし

EXPing にはない拡張として、次も受け付けます。

- 範囲指定 — `192.168.1.10-20` ／ `192.168.1.1-192.168.1.50` ／ `192.168.1.0/24`
- タブ区切り（表計算から貼り付けたとき用）

TCP で測りたい相手は「TCP」タブに書きます。こちらは末尾の `:ポート` が測る先です（`srv-01:445` など）。省略すると画面上の既定ポートを使います。

## 記録の書き出し

「記録」タブから 3 つの形式で出せます。

| 形式 | 向き |
|---|---|
| **HTML** | 1 ファイル完結（画像も CSS も埋め込み）。外部を一切読みに行かないので、客先のオフライン環境でも開けます |
| **テキスト** | 報告書に貼る・チケットに残す用途。等幅で桁が揃います |
| **CSV** | Excel で加工したいとき（BOM 付き UTF-8） |

HTML とテキストには次が入ります。

- **応答が無かった宛先**を先頭に抜き出し（「途中で途切れた宛先」とは別の節に分けています）
- **不通の記録**を時刻順に。いつ落ちていたかは平均値からは読み取れないので、機器の再起動やケーブルの抜き差しと突き合わせられるようにしています
- `ipconfig /all` の出力
- 無線 LAN の情報と周辺 AP の一覧 ※「無線」タブを一度開いていた場合のみ。位置情報の許可を求める時機が読めなくなるため、書き出しの拍子にスキャンはしません

## 見た目

明るい配色と暗い配色を切り替えられます（ヘッダ右の `☀` / `☾`）。選んだ配色は次回起動にも残ります。フォントは Noto Sans JP を exe に同梱しているので、どの端末でも同じ字面になります。

地と文字は無彩色にして、色を使うのはアクセントと状態バッジだけにしてあります。全面を色で塗ると、肝心の状態（応答あり・遅延・不達）が地に埋もれて読み取りづらくなるためです。

状態は**色だけで表していません**。`● 応答` / `✕ 不達` / `⊘ 拒否` のように記号と文字を必ず併記しています。文字と地のコントラストは、画面で使っている文字色と地色の組み合わせについて WCAG 4.5:1 以上を満たすよう、CI の自己診断が毎回検算しています。

## 動作環境

- Windows 10 / 11 (x64)
- **管理者権限は不要**です。ICMP・TCP・DNS・traceroute・ARP テーブルの読み取り・無線 LAN 情報のいずれも、通常のユーザー権限で動作します。
- 無線 LAN の情報は、Windows 11 24H2 以降では**位置情報の許可**が必要です（OS 側の仕様変更によるもの）。許可がない場合は画面に案内と設定への導線が出ます。

## 入手

[Actions](../../actions) の最新ビルドから成果物をダウンロードしてください。

| 成果物 | 展開後 | ダウンロード(zip) | 中身 |
|---|---|---|---|
| `PingWatcher-win-x64` | 約 125MB | 約 60MB | 単一 exe。.NET のインストール不要。こちらを推奨 |
| `PingWatcher-win-x64-runtime-required` | 約 5MB | 約 5MB | 軽量版。別途 [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) が必要 |

**サイズを最優先するなら軽量版**を選んでください（.NET 10 Desktop Runtime の導入が一度だけ必要です。中身はフォント同梱のアプリ本体のみ）。

WPF はトリミングできないため、.NET を同梱すると 125MB になります。単一ファイルの圧縮でサイズを半分にはできますが、メモリ消費が倍（約 183MB）になり初回起動も 5 秒近くかかるため採用していません。

### SmartScreen の警告について

コード署名をしていないため、初回起動時に「WindowsによってPCが保護されました」と表示されます。`詳細情報` → `実行` で起動できます。気になる場合はソースから自分でビルドしてください。

### ポートスキャンについて

「スキャン」タブのポート調査は既定で無効です。有効にすると、よく使う 22 ポートへ順に接続を試みます。**ウイルス対策ソフトや EDR が反応する場合があります。** 自分が管理権限を持つネットワークでのみお使いください。

## 保存先

設定と宛先リストは **exe と同じフォルダ**に置かれます。フォルダごと USB メモリに入れて持ち出せば、別の端末でも宛先リストがそのまま使えます。

| ファイル | 中身 |
|---|---|
| `settings.json` | すべての設定（Ping/TCP の宛先リスト・測定の既定値・配色・列幅） |
| `sessions\` | 作業セッションの記録 |
| `logs\` | 測定ログとスクリーンショット |
| `ftp\` | FTP で受け取ったファイル |
| `tftp\` | TFTP で受け取ったファイル |
| `sftp\` | SFTP でやり取りするファイル |
| `sftp-hostkey.txt` | SFTP サーバのホスト鍵 |

## 測定ログ

測定を開始するたびに `logs\ping-日時.log`（TCP は `tcp-日時.log`）が自動で作られ、**1 結果 1 行**のタブ区切りテキストで全結果が追記されます。不通の発生・復旧もイベント行として残るので、アプリを閉じた後でも「いつ・どこが・どれだけ切れていたか」を追えます。メモ帳で開けて、Excel にそのまま貼れます。

ログは 30 日より古いものを起動時に自動で片付けます（スクリーンショットは消しません）。メニューの「ファイル → 画面を撮って保存」(F12) で、いまの画面を PNG にして `logs\screen-日時.png` へ保存できます。

exe を `Program Files` のような書き込めない場所に置いた場合だけ、`%APPDATA%\PingWatcher\` へ保存します。書けるかどうかは、実際に 1 ファイル書いて消して確かめています。

ヘッダの「クリア」から、測定結果だけを消すか、宛先リストを残して起動直後の状態へ戻すかを選べます。

## ビルド

```
dotnet test tests/PingWatcher.Core.Tests/PingWatcher.Core.Tests.csproj
dotnet publish src/PingWatcher.App/PingWatcher.App.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:PublishReadyToRun=true -o publish
```

`PingWatcher.exe --selftest` で自己診断を実行し、終了コードを返します（CI で使っています）。XAML のエラーは実行して初めて落ちるため、この検査がビルド以外の唯一の確認手段です。

- MAC ベンダー名のテーブルを更新する — `python3 tools/oui/build_oui.py`（IEEE の登録簿から生成。CI では取得しません）
- アイコンを焼き直す — `tools/icon/build_icon.sh`（SVG から 16〜256px の 9 サイズを `.ico` に。ImageMagick が要ります）
