# PingWatcher

ぜんぶ同時に測る、Windows 向けネットワーク診断ツール。

EXPing のように宛先リストへ ping を打てますが、**宛先ごとに独立した周期で並列に測定する**ので、応答しない宛先が他の宛先を待たせません。ping のほかに TCP ping・DNS・traceroute・IP スキャン・無線 LAN の状態を 1 つのアプリにまとめ、測定結果はそのまま現場の証跡として書き出せます。

見た目はパステルカラーで、長時間眺めても疲れないことを狙っています。

## できること

| 画面 | 内容 |
|---|---|
| **監視** | 宛先ごとに独立した周期で並列 ping。状態バッジ・RTT・平均・ロス率・推移のスパークライン。行を選ぶと最小/最大/p95/ジッタ/MOS 値も出ます |
| **宛先** | EXPing と同じ書式でまとめて編集。範囲指定でサブネットを一気に登録できます |
| **スキャン** | 範囲を指定してサブネットを掃き、MAC・ベンダー名・ホスト名・開放ポートを一覧に。そのまま宛先へ追加できます |
| **DNS** | 同じ名前を複数の DNS サーバへ同時に問い合わせて横並び比較。A / AAAA / CNAME / MX / NS / TXT / SOA / SRV / PTR |
| **経路** | traceroute（TTL を並列に投げるので速い）、Path MTU 探索、経路変化の見張り |
| **無線** | 接続中 AP の詳細、受信強度の推移、チャンネルの混み具合、周辺 AP 一覧 |
| **記録** | グラフ入り HTML と CSV で書き出し |

### 宛先の書き方

「宛先」タブにまとめて書けます。書式は EXPing に合わせています。

```
# 本社ネットワーク
192.168.1.1 既定ゲートウェイ
192.168.1.10 ファイルサーバ
192.168.1.20-22 プリンタ

; 外部疎通
8.8.8.8 Google Public DNS
example.jp:443 自社サイト（TCP で確認）
```

- 1 行に 1 宛先。アドレスの後ろに**半角スペース**を空けると、そこから行末までが備考
- 行頭が `#` `;` `'` **全角スペース** の行は注釈として読み飛ばし

EXPing にはない拡張として、次も受け付けます。

- 範囲指定 — `192.168.1.10-20` ／ `192.168.1.1-192.168.1.50` ／ `192.168.1.0/24`
- 末尾に `:ポート` を付けると ICMP ではなく **TCP 接続**で測る（ping が塞がれた相手の確認に）
- タブ区切り（表計算から貼り付けたとき用）

## 動作環境

- Windows 10 / 11 (x64)
- **管理者権限は不要**です。ICMP・TCP・DNS・traceroute・ARP テーブルの読み取り・無線 LAN 情報のいずれも、通常のユーザー権限で動作します。
- 無線 LAN の情報は、Windows 11 24H2 以降では**位置情報の許可**が必要です（OS 側の仕様変更によるもの）。許可がない場合は画面に案内と設定への導線が出ます。

## 入手

[Actions](../../actions) の最新ビルドから成果物をダウンロードしてください。

| 成果物 | サイズ | 中身 |
|---|---|---|
| `PingWatcher-win-x64` | 約 125MB | 単一 exe。.NET のインストール不要。こちらを推奨 |
| `PingWatcher-win-x64-runtime-required` | 約 0.2MB | 軽量版。別途 [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) が必要 |

WPF はトリミングできないため、.NET を同梱すると 125MB になります。単一ファイルの圧縮でサイズを半分にはできますが、メモリ消費が倍（約 183MB）になり初回起動も 5 秒近くかかるため採用していません。

### SmartScreen の警告について

コード署名をしていないため、初回起動時に「WindowsによってPCが保護されました」と表示されます。`詳細情報` → `実行` で起動できます。気になる場合はソースから自分でビルドしてください。

### ポートスキャンについて

「スキャン」タブのポート調査は既定で無効です。有効にすると、よく使う 22 ポートへ順に接続を試みます。**ウイルス対策ソフトや EDR が反応する場合があります。** 自分が管理権限を持つネットワークでのみお使いください。

## 保存先

設定と宛先リストは **exe と同じフォルダ**に置かれます。フォルダごと USB メモリに入れて
持ち出せば、別の端末でも宛先リストがそのまま使えます。

exe を `Program Files` のような書き込めない場所に置いた場合だけ、
`%APPDATA%\PingWatcher\` へ保存します。

- `targets.json` — 宛先リストと測定の既定値

## ビルド

```
dotnet test tests/PingWatcher.Core.Tests/PingWatcher.Core.Tests.csproj
dotnet publish src/PingWatcher.App/PingWatcher.App.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:PublishReadyToRun=true -o publish
```

`PingWatcher.exe --selftest` で自己診断を実行し、終了コードを返します（CI で使っています）。

MAC ベンダー名のテーブルを更新するには `python3 tools/oui/build_oui.py` を実行してください（IEEE の登録簿から生成します。CI では取得しません）。
